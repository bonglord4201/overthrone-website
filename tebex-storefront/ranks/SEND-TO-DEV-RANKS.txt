OVERTHRONE SMP - Rank commands (for Tebex) + what each rank needs

Ranks, lowest to highest: RONIN -> VALKYRIE -> MONARCH -> GODBORN -> OVERLORD
Every rank includes everything from the ranks below it. Ranks are lifetime (one-time purchase).

=====================================================================
1. COMMANDS TEBEX WILL RUN (from the server console)
=====================================================================
{username} = the buyer's Minecraft name (Tebex fills it in).
These use LuckPerms (it has a NeoForge 1.21.1 version). If you use a different
permissions mod, tell me your command format and I'll change Tebex.

RANK       PURCHASE                                        REFUND / CHARGEBACK
Ronin      lp user {username} parent add ronin             lp user {username} parent remove ronin
           classtoken give {username} 1                    classtoken take {username} 1
Valkyrie   lp user {username} parent add valkyrie          lp user {username} parent remove valkyrie
           classtoken give {username} 2                    classtoken take {username} 2
Monarch    lp user {username} parent add monarch           lp user {username} parent remove monarch
           classtoken give {username} 3                    classtoken take {username} 3
Godborn    lp user {username} parent add godborn           lp user {username} parent remove godborn
           classtoken give {username} 4                    classtoken take {username} 4
Overlord   lp user {username} parent add overlord          lp user {username} parent remove overlord
           classtoken give {username} 5                    classtoken take {username} 5

- "classtoken" = the Class Reset Tokens each rank gets on purchase (1x-5x).
  This command does NOT exist yet - please make it, or send me your real command.
- Each rank also has a Discord Action in Tebex to give the matching Discord role.

=====================================================================
2. LUCKPERMS SETUP
=====================================================================
Create the groups and make each one inherit the rank below, so perks stack:

  lp creategroup ronin
  lp creategroup valkyrie
  lp creategroup monarch
  lp creategroup godborn
  lp creategroup overlord

  lp group valkyrie parent add ronin
  lp group monarch parent add valkyrie
  lp group godborn parent add monarch
  lp group overlord parent add godborn

  lp group ronin setweight 10
  lp group valkyrie setweight 20
  lp group monarch setweight 30
  lp group godborn setweight 40
  lp group overlord setweight 50

Chat/tab prefixes (colours: Ronin red, Valkyrie purple, Monarch orange-gold,
Godborn pale gold, Overlord bright red):
  lp group ronin meta setprefix 10 "&c[RONIN] "
  lp group valkyrie meta setprefix 20 "&d[VALKYRIE] "
  lp group monarch meta setprefix 30 "&6[MONARCH] "
  lp group godborn meta setprefix 40 "&e[GODBORN] "
  lp group overlord meta setprefix 50 "&4[OVERLORD] "
(Prefixes only show in chat/tab if the server has a chat/tab mod that reads LuckPerms meta.)

Optional - a track so staff can promote/demote in order:
  lp createtrack donor
  lp track donor append ronin
  lp track donor append valkyrie
  lp track donor append monarch
  lp track donor append godborn
  lp track donor append overlord
